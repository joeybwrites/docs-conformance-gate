# Plugins

A plugin bundles skills, MCP connectors, slash commands, sub-agents, and hooks into one package.

Skills apply task-specific instructions. MCP connectors give access to external tools. Slash commands trigger workflows. Sub-agents handle delegated work. Hooks run at defined points in a session.
